## Refleksi

Pada latihan katalog buku, saya belajar bahwa masukan pengguna perlu dinormalisasi
sebelum dibandingkan. Dengan `strip()` dan `casefold()`, pencarian tetap bekerja
meskipun ada spasi tambahan atau perbedaan huruf besar-kecil. Saya juga menambahkan
tes `assert` agar perilaku filter level dan pencarian subjek bisa diperiksa otomatis.
