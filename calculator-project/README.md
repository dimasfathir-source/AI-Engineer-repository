# Calculator Project 🧮

## 📋 Deskripsi
Program kalkulator interaktif yang memungkinkan user memilih operasi matematika dasar (penjumlahan, pengurangan, perkalian, pembagian) dan memasukkan angka sendiri.

## 🎯 Features
- ✅ Menu interaktif dengan pilihan operasi
- ✅ Input user untuk angka pertama dan kedua
- ✅ Error handling untuk pembagian dengan nol
- ✅ Try-except untuk validasi input
- ✅ Fungsi-fungsi terpisah untuk setiap operasi

## 🛠️ Tech Stack
- Python 3.11

## 📦 Installation
```bash
# 1. Clone repository
git clone https://github.com/dimasfathir-source/AI-Engineer-repository.git

# 2. Navigate ke folder
cd AI-Engineer-repository/calculator-project

# 3. Run program
python calculator.py
```

## 🚀 Usage
Jalankan program:

```bash
python calculator.py
```

Kemudian ikuti menu:
Selamat datang di Kalkulator Sederhana!
Pilih operasi:

Penjumlahan
Pengurangan
Perkalian
Pembagian
Masukkan pilihan: 1
Masukkan angka pertama: 5
Masukkan angka kedua: 3
Hasil: 8.0
