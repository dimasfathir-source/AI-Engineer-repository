# Perpustakaan Digital

Website perpustakaan digital dengan katalog publik, panel admin pustakawan,
dan (dalam pengembangan) klasifikasi DDC otomatis dengan n8n + Gemini.

## Fitur
- Katalog publik: pencarian, filter bahasa dan subjek, halaman detail
- Panel admin: login, tambah, edit, ubah status, dan hapus koleksi
- Keamanan: Row Level Security di database

## Teknologi
HTML, CSS, JavaScript, Supabase (database + autentikasi), n8n

## Struktur folder
(tempel pohon folder di atas)

## Cara menjalankan
1. Clone repo ini
2. Isi config.js dengan URL dan kunci publishable Supabase
3. Jalankan dengan Live Server di VS Code
